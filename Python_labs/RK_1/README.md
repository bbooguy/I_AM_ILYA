# РК 1. HTTP-клиент и EDA-анализ

Решение [задания РК 1](https://github.com/Kulikova-A18/python-iu8-13M-2026-2027/tree/main/rk-1): загрузка данных через REST API, валидация с помощью Pydantic и разведочный анализ в pandas.

## Файлы

- `client.py` — HTTP-клиент с Basic Auth, пять Pydantic-моделей с алиасами и поддержкой null, обработка ошибок соединения, таймаутов и статусов 401/403/404/5xx. Данные объединяются по `id` через inner join и сохраняются в `sql_injections_merged.csv`.
- `eda.ipynb` — все 12 пунктов анализа: общая информация, категории и типы атак, инструменты, MITRE-техники, теги, источники, связи между полями, длины текстов, слова в рекомендациях и итоговая сводка. Анализ сопровождается таблицами, графиками и выводами.
- `requirements.txt` — зависимости для запуска.

## Запуск

Требуется Python 3.10 или новее. Выполните команды в папке решения:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python client.py
jupyter lab eda.ipynb
```

В Windows для активации окружения используйте `.venv\Scripts\activate`.

Клиент обращается к `http://193.233.171.205:8000` с учётными данными `student` / `student_pass`. CSV не включён в решение: перед повторным выполнением ноутбука его нужно создать командой `python client.py`. Затем в Jupyter выполните **Restart Kernel and Run All Cells**. Загрузка может занять несколько минут; таймаут настраивается в вызове `APIClient`.
