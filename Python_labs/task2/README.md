# Задание №2: игровая статистика с Pydantic

Реализация задания №2 с Pydantic 2. Требуется Python 3.10+.

```sh
python3 -m pip install -r requirements.txt
python3 server.py
```

В другом терминале из этого же каталога:

```sh
python3 client.py
```

Сначала автоматически выполняются проверки API и устойчивости из edge_cases.py.
Если они прошли, клиент предлагает перейти в ручной режим: ответьте `да`
для продолжения или нажмите Enter / введите `нет` для выхода.
В ручном режиме введите HTTP-метод, путь и JSON-тело отдельными строками. Пустое тело — Enter,
выход — `exit` вместо метода. Тело отправляется как введено: можно вручную
проверить даже битый JSON. Например: `GET`, `/users`, пустое тело; `GET`,
`/users/user2`, пустое тело; `POST`, `/users/user1/score`, `{"score": 500}`;
`DELETE`, `/users`, пустое тело.

`GET /users` возвращает объект с идентификаторами и данными всех пользователей.
`POST /users/<id>/score` добавляет целое неотрицательное число к счёту.
Данные хранятся в памяти и сбрасываются при перезапуске.

Автоматические проверки запускаются отдельно: `python3 edge_cases.py`.
Они добавляют 500 очков user1.

Задание №1 без Pydantic находится в соседней папке task1.
Не запускайте оба сервера одновременно на стандартном порту 8000.

Автотесты отправляют реальные POST-запросы и меняют счёт user1: на 500 очков за запуск.

В ручном режиме введите `help` вместо HTTP-метода, чтобы увидеть примеры
успешных и ошибочных запросов. После подсказки можно продолжить ввод.
