# Задание №2: игровая статистика с Pydantic

Установите зависимость: `python3 -m pip install -r requirements.txt`.

В одном терминале из этого каталога запустите `python3 server.py`.
В другом выберите режим клиента:

- `python3 client.py` — автотесты, затем сразу ручной режим до команды exit;
- `python3 client.py test` — только автотесты;
- `python3 client.py interactive` — сразу ручной режим без автотестов.

В ручном режиме запрос вводится одной строкой:

```text
GET /users
GET /users/user2
POST /users/user1/score {"score": 500}
```

Команды: `help` — примеры запросов, `test` — повторить автотесты,
`exit` — выйти. Некорректный JSON отправляется как введён, чтобы проверить
обработку ошибок сервером.

Автотесты находятся в client.py и проверяют ответы и сохранение состояния
после ошибок и обрывов соединения. edge_cases.py также запускает эти проверки.
Каждый успешный прогон добавляет 500 очков user1.
Данные хранятся в памяти и сбрасываются при перезапуске сервера.

В task2 score проверяется Pydantic: только целые неотрицательные числа.
Оба сервера используют порт 8000: запускайте их по очереди.

Журналы client.log и server.log создаются рядом с соответствующими скриптами.
Они записывают время, запросы, ответы и ошибки, дополняются при каждом запуске
и не отправляются в GitHub. Вывод в терминал сохраняется.

`GET /error` демонстрирует внутреннюю ошибку: сервер возвращает
`500 Internal Server Error` с JSON и продолжает принимать запросы.
Автотесты проверяют этот случай и методы PUT/PATCH. Непредвиденные ошибки
GET/POST записываются в server.log с подробностями и возвращают JSON с кодом 500.
В журнал сервера также записывается полученное тело POST-запроса.

Вопросов да/нет нет. После автотестов вводите запросы, для завершения — `exit`.
`help` показывает примеры для кодов 200, 400, 404, 405 и 500.
