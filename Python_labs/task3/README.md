# ДЗ 3. Анализ кода через Semgrep

Цель — проверить предоставленный TCP-сервер банка и составить таблицу с результатами и выводами согласно [заданию](https://github.com/Kulikova-A18/python-iu8-13M-2026-2027/tree/main/dz-3).

## Файлы

- `main.py` — исходный файл преподавателя, без исправлений.
- `scan.sh` — загрузка официальных Python-правил и запуск проверки.
- `semgrep-report.json` — фактический результат Semgrep в JSON.
- `report.md` — таблица срабатываний, их разбор и итоговые выводы.
- `requirements.txt` — версия Semgrep для воспроизведения проверки.

## Запуск

Linux или macOS, Python 3.10+ и Git:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
bash scan.sh
```

Semgrep запускается из виртуального окружения, поэтому установка через Homebrew необязательна.

Первый запуск требует доступа к GitHub для загрузки правил. Проверяется только `main.py`; запускать сервер и скрипты атак для этого задания не требуется. Правила зафиксированы на конкретном коммите, чтобы обновления репозитория не меняли результат. В macOS используется переносимое копирование YAML вместо GNU-команды `cp --parents` из примера задания.

Готовые результаты приведены в [report.md](report.md). Semgrep нашёл 6 совпадений: 5 уровня WARNING и 1 уровня ERROR. Эти уровни назначены правилами и не равны оценке реальной опасности проблемы.

Зависимость Pydantic для сканирования не нужна: Semgrep анализирует исходный текст, не исполняя `main.py`.

## Выполненный локальный запуск

Проверка выполнена на macOS 17 октября 2026 года. Журнал сохранён в `scan.log`, оригинальный JSON — в `semgrep-report.json`. В этом сеансе использованы изолированное окружение `/tmp/dz3-semgrep-env` и правила `/tmp/dz3-semgrep-rules`; для самостоятельного повторения используйте команды выше, так как временные каталоги могут быть очищены.

## Демонстрация преподавателю

В Терминале откройте папку работы и выполните:

```bash
python3 demo.py
```

Скрипт использует установленный Semgrep или создаёт `.venv` и устанавливает его. Затем запускает `scan.sh`, показывает сводку из JSON, каждую находку со строками `main.py` и текст `report.md`. Между этапами нажимайте Enter. Первый запуск требует интернета и может занять несколько минут — лучше выполнить его заранее.

Без остановок: `python3 demo.py --no-pause`.
Просмотр сохранённых результатов без новой проверки и без установки зависимостей: `python3 demo.py --report-only`.

`report.md` не обновляется скриптом: при изменении исходника или находок таблицу нужно пересмотреть.
