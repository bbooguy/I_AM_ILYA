# Задание №1: игровая статистика пользователей

Только стандартная библиотека Python, без Pydantic и других зависимостей.
Данные хранятся в обычном словаре USERS_DATA в server.py.

Из этого каталога запустите сервер:

```sh
python3 server.py
```

В другом терминале запустите `python3 client.py`.
Введите HTTP-метод, путь и JSON-тело отдельными строками. Пустое тело — Enter,
выход — `exit` вместо метода. Тело отправляется без предварительной проверки,
поэтому можно вручную проверить битый JSON.

Маршруты:
- `GET /users` — все пользователи с идентификаторами;
- `GET /users/<id>` — данные одного пользователя;
- `POST /users/<id>/score` с `{"score": 500}` — добавить очки.

score должен быть числом: целым или дробным. Строки и bool отклоняются.
Задание №1 не задаёт ограничение ge=0, поэтому отрицательные значения разрешены.
NaN, Infinity и переполнение отклоняются с 400.
Данные сбрасываются при перезапуске сервера.

Проверки: `python3 edge_cases.py`. Подробности — в REPORT.md.
Задание №2 с Pydantic находится в соседней папке task2.
Не запускайте оба сервера одновременно на стандартном порту 8000.
